# Fretboard Freedom · Level 2: Deck Plan

The follow-up to Level 1, for a player who has worked through Level 1. They know the fretboard map, the 5 A-minor pentatonic boxes, CAGED in A, top-string triads, basic arpeggios, the blues scale, three modes and the common jam forms. The examples still lean toward **blues & rock** and **rock & metal**.

**Format:** .pptx, 16:9, 80 slides, using the same design system as Level 1:
- The same color code: root red, 3rd amber, 5th blue, 7th purple, teal for the special or flavor note, gray for other scale notes.
- Diagrams generated by code and verified against the theory engine.
- Detailed speaker notes on every slide.
- A "Practice this" slide that ends each part.
- A printable practice log and cheat sheets.

**New visual tools:**
- **Rhythm grids:** a piano-roll beat grid with counts ("1 e & a") under each cell, so no standard notation is needed.
- **Tuning-aware fretboards and tab:** for Drop D, E♭ standard, D standard and Drop C.

**Default keys:**
- **A** for blues and rock.
- **E** for metal.
- **A natural minor / C major** for the full-scale positions, so they line up exactly with the 5 pentatonic boxes you already know.
